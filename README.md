# ICMAB Homepage Clone

Static HTML clone of the [ICMAB](https://icmab.gov.bd) homepage with interactive Bangladesh map, hero section, affiliations slider, promo videos, and welcome popup.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/icmap.html`

## Main files

- `icmap.html` — main page
- `bd-map-data.js` — interactive map data
- `assets/` — images, videos, partner logos
